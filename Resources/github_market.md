## 方法与限制

- 硬过滤：所有候选均来自 `stars:>=1000` 查询。
- 周期口径：按仓库 `created_at` 所在 ISO week 回溯，不等同于真实 Trending 入榜周。
- 排序口径：GitHub Search API 按采集时当前 stars 排序，stars 不是历史当周数值。
- 去重规则：仓库一旦在较早 week 收录，后续 week 如再次出现会跳过，且不计入后续 week 的 20-30 个目标名额。
- 相关性规则：保留 coding agent、开发工具、MCP/tool calling、IDE、自动化测试、文档/数据、repo 运维、嵌入式/硬件/EDA 等工程相关项目；剔除明显消费娱乐或泛 demo 项。
- source confidence 统一为 C 级：GitHub Search API approximate candidate pool。
